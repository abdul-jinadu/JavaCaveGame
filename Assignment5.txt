//* What I Learned
* The feature in Java that I learned about while looking through this code was the concept of inheritance. 
* It allows one class to use stuff from another class instead of rewriting the code again.
* In the game, the Charcter class is an abstract base class while bother the Player and Enemy classes are built from it.
* This means that players and enemies can share behaviors define in Charcter.
* This entire project uses it to organize different types of charcters in game, while allowing them to de distinct as well.
* I think inheritance is useful because it makes the code easier to organize and reduces the amount of repeated code used in the program making it more labor and time efficent.
* Learning about this method helped me understand how connectedd different classes are in the game to one another.
